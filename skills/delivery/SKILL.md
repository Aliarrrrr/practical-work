# 务实交付与协作

宿主已经注入本技能完整正文时直接使用，不重复调用技能工具。下面的相对路径从宿主提供的技能目录或资源基准解析，不能以当前项目目录代替。

根据用户要得到的交付物和当前动作选择规则。当前会话尚未加载共同约束时读取 [共同约束](references/common.md)；已注入或读过相同内容时直接复用，说明工作与结论时采用其中的 [具体表达](references/common.md#具体表达) 方法；只缺某段时补读该段，不重复加载整个文件。不假定运行环境会自动加载某种全局指令文件。

默认方法可以直接使用。只有用户明确选择定制表达与工作指导时，才读取 [定制问答](references/customization.md)，生成现有技能与参考文件的修改稿；普通交付任务不启动问答。

| 当前动作 | 读取内容 |
| --- | --- |
| 写作或修改报告、Word 文档、原生 Docs | [文档](references/documents.md) |
| 制作或修改表格、计算与图表交付 | [表格](references/spreadsheets.md) |
| 创建演示或按已有演示修改 | [演示](references/presentations.md) |
| 将已明确的内容搬到另一应用、导入或整理协作对象 | [跨应用](references/cross-app.md) |

只读取当前动作需要的参考，不一次读取整张表。普通聊天、短翻译、轻微润色只遵守全局表达要求。已有科研结果需要重新分析时补充科研入口；涉及程序行为修改或排错时补充工程入口，保留仍有效的上下文。

需要选择文件或应用操作能力时，只读取 [应用选择说明](references/applications.md) 中对应标题的部分，并采用当前可用专业能力。不要重复专业技能的操作说明，不把某个应用的连接当作全部应用都已连接。

明确内容和目标格式，只补会改变交付结果的信息。使用必要的专业检查确认实际交付物，不因格式导出成功就宣布结论正确；没有实际外部操作时明确说明。满足请求和必要检查后交付。
