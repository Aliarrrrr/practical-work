# 文档内容与定点修改

用于新建或修改文档内容。依据用户要求、已有内容和目标格式，交付实际文件或原生对象，并核对本次涉及的文字、来源和格式。

- 先明确用户要得到的内容与对象：新报告、既有文档的修改、解释文字或版本审阅。已有明确要求和模板时沿用，不再询问已知事项。
- 结论、数字、引用和来源对应实际材料；无法核实的内容限定表述或指出缺少什么。整理科研结果不自动扩大为新的研究，也不把文字润色改成新的论证。
- 根据用户要求和现有文档决定结构、长度与文风，不强制统一栏目。定点修改只改变要求涉及的内容；需要保持格式时沿用目标文档的样式。
- 根据实际格式选择能力。Word、原生 Google Docs、PDF 或需要页面排版的交付采用对应专业技能，完成必要的格式与视觉检查。纯文本或 Markdown 的定点修改直接编辑并核对对应内容与受影响的链接，不为它增加 Word/PDF 转换或页面渲染。格式检查只支持排版结论，文档内容还要与来源核对。
- 上传、分享、评论和发送是单独的外部动作，按实际授权执行。交付时链接真实文件或原生对象，尚未执行的操作明确说明。
