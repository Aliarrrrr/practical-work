# 务实科研

宿主已经注入本技能完整正文时直接使用，不重复调用技能工具。下面的相对路径从宿主提供的技能目录或资源基准解析，不能以当前项目目录代替。

当前会话尚未加载共同约束时读取 [共同约束](references/common.md)；已注入或读过相同内容时直接复用，说明工作与结论时采用其中的 [具体表达](references/common.md#具体表达) 方法；只缺某段时补读该段，不重复加载整个文件。不假定运行环境会自动加载某种全局指令文件。涉及应用选择时，只读取 [应用选择](references/applications.md) 的相关部分。

默认方法可以直接使用。只有用户明确选择定制表达与工作指导时，才读取 [定制问答](references/customization.md)，生成现有技能与参考文件的修改稿；普通科研任务不启动问答。

围绕用户当前要理解、比较、复现或分析的问题工作。先利用已有论文、数据、代码和结果解决会影响结论的未知；只有无法查明且会改变研究判断或计算安排的信息才询问。执行范围限于文献、计算和数据，不执行实验室或现场操作。

只读取当前动作需要的参考，任务变化时再追加：

| 当前目的 | 参考 |
| --- | --- |
| 理解论文、比较主张与研究结果 | [文献理解](references/reading.md) |
| 定义研究问题、比较变量与研究设计 | [研究设计](references/study-design.md) |
| 复现计算结果、安排计算实验 | [计算复现](references/experiments.md) |
| 清理与分析科学数据、解释统计结果 | [数据分析](references/data-analysis.md) |
| 评估机器学习方法、选择分割与指标 | [机器学习](references/machine-learning.md) |

交付用户需要的解释、比较、设计或结果。区分文献作者报告、已执行计算得到的结果和自己的推断；结论只覆盖实际使用的材料、数据与条件。不要为普通科研任务预设固定流程、重复次数、额外文档或审批。

混合任务可以按实际需要追加工程排错或交付入口。处理代码、图表、文稿或其他产物时，保留已有有效的研究问题、数据范围、方法与结果，不因切换入口重做全部科研工作。文件和应用的具体操作交给已有相关技能，本入口不重复它们的操作说明。
