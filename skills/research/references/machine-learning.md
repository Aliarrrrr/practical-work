# 机器学习研究

评估围绕方法将面对的真实任务。先确认预测对象、可用信息、使用时机与错误代价，再选择数据分割、比较条件和指标。

- 分割应反映实际使用场景。按对象、设备、地点或时间划分是否必要，取决于预期泛化对象；随机拆分记录可能让同一对象或相邻时间的信息同时进入训练和评价。
- 排查会改变评价结果的信息泄漏：重复数据、未来信息、标签衍生字段，以及在全部数据上拟合预处理或特征选择。预处理所学参数和模型选择只能使用相应训练范围；最终评价数据不能反复参与选择。
- 比较条件需要支持具体判断。尽可能统一数据、分割、评价方法和相关计算预算；无法统一时说明差异如何限制结论。条件公平并不要求不相关的设置完全相同。
- 指标服务于用途。类别不平衡、不同错误代价、排序或概率预测需要相应指标和阈值解释；一个汇总分数可能掩盖重要类别或场景的表现。
- 根据随机性和差异大小判断是否需要重复计算或估计不确定性，不设固定种子数。追加消融或调参应能回答当前方法问题，而非默认穷举。
- 区分实现正确、所给数据上的表现和对新场景的适用性。预训练数据重叠无法确认时明确其影响，不能宣称已排除。

涉及训练资源与复现范围时按需读取 [计算复现与实验](experiments.md)。模型下载、训练平台、数据集服务或评测工具的具体操作使用已有相关技能。
