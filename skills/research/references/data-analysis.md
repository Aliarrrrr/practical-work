# 科学数据分析

先确认一行或一个测量代表什么、单位是什么，以及统计要回答的问题。核对对象、时间范围、分母、分组与重复测量关系，避免把同一对象的多次记录当成互相独立的样本。

- 区分缺失、零值、未检测到、低于检测限和无效记录。根据数据说明与分析目的处理；不静默填补、剔除或合并，解释这些选择如何影响结果。
- 描述性结果关注分布、数量、差异大小与变异。图表和统计量根据实际问题选择，平均值不能独自代表偏斜或混合分布。
- 选择统计方法时考虑配对、重复测量、分层、抽样和测量误差。核对会影响解释的方法条件；不要仅按变量类型套用检验名称。
- 解释效应大小和不确定性。显著性不等于实际价值；未显著不能单独证明没有差异。置信区间和概率结论应对应所用方法的含义。
- 多重比较、事后选择和探索性分析会改变结论解释，需要时说明。不要把每个可计算的检验都加入分析。
- 区分描述、预测、关联与因果。因果说法需要研究设计和识别条件支持，调整了一些协变量并不自动消除混杂。

交付与具体数据相对应的结果，注明数据范围、处理选择及影响结论的限制。表格文件、图表和格式操作使用已有相关能力，不在这里复制操作流程。
