# 应用与工具选择

仅在需要选择操作能力时读取对应标题下的内容，不为一个任务读取全部说明。按用户目标、对象位置和当前宿主实际提供的工具选择；文件扩展名不足以决定场景。

先查看当前可用技能、工具、CLI 与已连接会话。专业技能适用时读取其说明；没有对应技能但已有合适工具时直接使用。不同 agent 的工具和技能名称不相同，不能把本文提及的能力当作已经安装、连接或获得授权。相对路径从当前技能目录解析，不能依赖某个插件缓存或本机绝对路径。

## 文献与 PDF

研究结论由科研入口负责。按实际文献来源选检索与原文获取能力，技术问题优先原始论文和官方材料；不要把检索片段当成全文阅读。Hugging Face、arXiv 或其他来源有对应论文能力时采用；没有时使用可用检索和原文获取工具，并说明实际读到的范围。

需要读取 PDF 图表、页面布局或制作 PDF 时采用可用的 PDF 技能或解析与渲染工具。已有文字足够回答标题翻译或短解释时不启动 PDF 渲染。存在多份相关技能时选适合当前环境的一份，不重复执行。

## 本地文档与文件

创建或修改 Word、独立表格文件及演示文件，选择能处理其真实格式的文档、表格或演示技能与工具。专业能力负责文件格式、计算、渲染和检查；本插件负责内容、范围与结果判断。需要匹配用户文风时采用已有写作规则，轻微修改不自动加载整套文风指导。

科学图表使用真实数据与标准绘图工具。说明机制或交互探索可使用可用的可视化能力；照片或插画才采用图像生成，不能生成貌似数据图的图片冒充计算结果。读取或编辑文件优先文件能力，不自动改为浏览器或桌面操作。

## Google Drive

通过当前可用的 Drive 检索或文件能力核对原生对象，再采用 Docs、Sheets 或 Slides 对应操作能力。已有专业技能规定统一 Drive 入口时遵守该入口；用户已提供文件标识或链接时先核对目标，不重复搜索无关文件。

已有原生 Google Slides 模板、参考或待修改演示时，采用能读取并沿用其结构的操作能力；没有既有原生参考的新演示按当前演示技能的实际范围选择交付方式。不能用本地导出再上传代替要求保留的原生结构。Drive 查询、Docs 写入、Sheets 范围修改和评论是不同动作，获准创建报告不等于获准分享或评论。

## 实时 Excel 与浏览器

用户指定正在打开的 Excel 工作簿或已有实时会话时使用该会话的可用接口；独立 `.xlsx`、`.csv` 文件采用文件表格能力。不能修改另一个磁盘副本并声称已经修改当前工作簿。没有实时连接时说明缺少连接，完成不依赖它的工作。

需要访问页面、填写表单或观察界面时采用实际可用的浏览器能力，遵守用户指定浏览器、标签页和会话。适合终端自动化时可使用 Playwright 等工具；已指定现有标签页时使用能访问该标签页的能力。只有实际可用的原生应用接口才可操作原生界面，不能从技能存在推断接口可用。

## Hugging Face 与计算资源

论文、模型与数据集按实际任务采用论文工具、Hub CLI 或数据集能力。代码实际使用 Transformers.js、Gradio 等库时读取相应指导，一般论文解释不加载这些开发规则。

训练、评测与云计算分别采用对应能力。判断本机复现可行性只检查资源与任务规模，不自动创建云任务、训练任务或购买算力。外部成本和写入受用户授权及工具要求限制，无法确认资源时说明影响判断的未知。

## GitHub 与项目协作

用户要求处理 PR、仓库、问题或 Jira、Linear 等对象时采用对应已连接工具，或适合当前仓库的 CLI。指定审查不自动扩大为全仓库扫描；明确的安全审查采用实际可用且范围适合的安全技能或工具。

发布、发送消息、评论、分享与其他外部写入分别核对实际授权，不能由“协作”二字推断许可。授权已经明确时完成已授权工作，不为每个低影响动作再次询问。

## 缺少能力

先检查当前实际可用工具、技能和连接。宿主提供插件管理或工具发现能力时按需查找；没有时准确说明缺少的能力，不假装调用不存在的发现工具。不为已有功能推荐冗余插件；不能因缺少某个技能名称就断言所有对应功能不可用。

连接不可用就说明未完成的操作，继续不依赖该连接的工作。需要用户补充账号、成本或授权时只询问确实影响结果的条件，不能默认添加服务、后台进程或账号连接。
