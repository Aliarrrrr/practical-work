# 应用与工具选择

仅在需要选择操作能力时读取对应标题下的内容，例如搜索标题并读取相应行；不要为一个应用任务读取全部说明。按用户当前目标、对象位置及可用能力选择，不能仅凭文件扩展名选择场景。技能名称用于在当前目录中找到入口，不绑定安装版本或缓存路径。

## 文献与 PDF

研究结论由科研入口负责。检索按实际文献来源选工具，技术问题优先原始论文和官方材料；不要把检索片段当成全文阅读。用户给出 Hugging Face 或 arXiv 论文时，采用可用的 `hugging-face:huggingface-papers`；其他学科使用适合来源的检索与原文获取能力。

需要读取 PDF 图表、页面布局或创建 PDF 时使用可用的 PDF 技能；已有文字足够回答标题翻译或短解释时不启动 PDF 渲染。两份 PDF 技能同时存在时选与当前运行环境和任务相符的一份，不重复执行。

## 本地文档与文件

创建或修改 `.docx` 使用 `documents:documents`，表格文件使用 `spreadsheets:Spreadsheets`，演示文件使用 `presentations:Presentations`。专业技能负责文件格式、计算、渲染与检查；本插件负责内容、范围和结果判断。已授权写作需匹配用户文风时使用 `write-like-me:write-like-me`，轻微修改不自动加载文风规则。

科学图表使用真实数据与标准绘图工具。说明机制或交互探索可采用 `visualize:visualize`；照片或插画任务才采用图像生成，不能生成貌似数据图的图片来冒充计算结果。读取已有文件优先文件能力，不自动转为浏览器或桌面操作。

## Google Drive

通过 `google-drive:google-drive` 定位与检查原生对象，再使用 `google-drive:google-docs`、`google-drive:google-sheets` 或对应 Slides 操作技能。用户已提供文件标识或链接时先核对目标，不重复搜索无关文件。

已有原生 Google Slides 模板、参考或待修改的演示采用 `google-drive:google-slides`；没有既有原生参考的净新演示按 `presentations:Presentations` 的能力选择交付方式。Drive 查询、Docs 写入、Sheets 范围修改和评论分别是不同操作；不得因获准创建报告就推断获准分享或评论。

## 实时 Excel 与浏览器

用户标记 Excel 应用或已有实时会话时，使用 `spreadsheets:excel-live-control` 及实际连接会话；独立 `.xlsx`、`.csv` 文件使用文件表格技能。不能把实时会话操作替换成修改另一个磁盘副本并声称已修改当前工作簿。

需要访问页面、填写表单或观察界面时使用当前可用浏览器能力，并遵守用户指定的浏览器、标签页和会话。终端自动化适用时采用 `playwright`；已指定现有标签页时使用对应标签页能力。只有实际可用的原生应用接口才可操作原生界面，不能从技能存在推断接口可用。

## Hugging Face 与计算资源

论文、模型与数据集按任务使用论文工具、Hub CLI 或数据集技能。实际代码涉及 Transformers.js 或 Gradio 时使用对应技能；一般论文解释不加载它们。

训练、评测和云计算分别选对应训练、评测或 Jobs 技能。判断本机复现可行性只检查资源和任务规模，不自动创建云任务、训练任务或购买算力。外部成本和写入受用户授权及工具要求限制，无法确认可用资源时说明影响判断的未知。

## GitHub 与项目协作

用户要求处理 PR、仓库、问题或 Jira/Linear 等对象时，使用对应已有连接或适合当前本地仓库的 CLI。指定审查不自动变为全仓库扫描；明确安全审查按 `codex-security` 对应范围技能处理。

发布、发送消息、评论、分享和其他外部写入分别核对实际授权，不能由“协作”二字推断许可。授权已明确时完成已授权工作，不为每个低影响动作再次询问。

## 缺少能力

先查看当前可用工具、已安装技能和连接状态。实际缺少外部能力时按 `plugin-management:plugin-management` 查找适合的插件；不为已有的原生搜索、图像生成等能力推荐冗余插件。连接不可用就说明未完成的操作，继续不依赖该连接的工作，不假装成功。
