# Practical Work 0.3.2

日期：2026-10-16。

本轮根据 [0.3.1 版本验收](acceptance-0.3.1.md) 中的重复读取与输出字节问题调整指导，并补齐中英文 README。它是指导文字的微调，没有重新运行被测模型任务，不能据此宣称行为已经改善。

## 改动

- 三入口明确区分首次读取、复用已加载内容和只补读缺失段落，合并此前分开的共同约束与具体表达加载说明。
- 共同参考要求复用上下文已有材料；文件已变、内容不足、来源版本不明且影响判断，或用户明确重查时才补读。继续对话或切换步骤本身不要求重读。
- 工程参考仅在任务明确要求逐字输出或保留文件字节、编码、换行时核对原始字节，说明文本模式可能归一化换行。普通改动不因此增加逐字节检查。
- `README.md` 与 `README.en.md` 提供语言切换和相同的安装、导出、更新命令；技能正文与参考仍为中文。两份文档均区分历史客户端记录、本版检查和未完成的效果评测。
- 四份插件/扩展清单升级为 `0.3.2`，共同参考同步到三个技能。

上述输出字节指导依据已有失败的实际输入/stdout 检查编写，不把源码或测试文件行尾变化当成输出错误，也不将失败归因插件。
